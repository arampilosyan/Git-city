# 🏙️ Git քաղաք 3D

Քո GitHub/Git repository-ների 3D վիզուալիզացիա։ Յուրաքանչյուր repository շենք է, շենքի բարձրությունը և լուսավոր պատուհանների քանակը կախված են commit-ների քանակից, իսկ մեկ repository = մեկ բնակիչ։

## Ինչպես օգտագործել

1. Բացիր `index.html`-ը բրաուզերում (կամ GitHub Pages-ի հղումով)։
2. Գործարկիր `./collect.sh /ճանապարհ/դեպի/նախագծերի/թղթապանակ`։
3. Արդյունքը տեղադրիր էջի տեքստային դաշտում և սեղմիր «Կառուցել քաղաքը»։

## Հնարավորություններ

- 3D տեսարան (three.js), պտույտ, մոտեցում
- օր / գիշեր ռեժիմ
- ստվերներ և մառախուղ
- շենքի վրա պահելիս երևում են անունը և commit-ների քանակը

## Տեղադրում GitHub Pages-ով

Repository-ի էջում՝ **Settings → Pages → Build and deployment**․ ընտրիր Branch՝ `main` և թղթապանակ՝ `/ (root)`։ Մի քանի րոպեից էջը կհասանելի լինի `https://<քո-անունը>.github.io/<repo-ի-անունը>/` հասցեով։
